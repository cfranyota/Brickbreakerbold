# Brickbreakerbold

BrickBreaker Bold rebuilt for current phones, including square screens. The Android install file is `public/BrickBreakerBold.apk`.

The original BlackBerry 10 game was made by the Browser Team at Research In Motion under the Apache License 2.0. Authors Xinyuan Fan and Pawel Chomicki.

## Run

```
npm install
npm run dev
```

Open the local site. On a square screen the board fills the display. On a tall phone it stays a portrait game.
